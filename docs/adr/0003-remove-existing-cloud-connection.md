# ADR-0003: firmware から既存クラウド接続を削除する

- Status: Accepted
- Date: 2026-06-12
- 関連: ADR-0001, ADR-0002（「影響」に記載した未決事項を本 ADR で解決）

## コンテキスト

既存 firmware は公式クラウド（XiaoZhi AI 連携、アカウント管理、アプリストア等）への接続機能を持つ。ADR-0002 では「既存クラウド接続と新 backend 接続の切り替えが必要になる可能性」を未決事項として残していたが、オーナーの判断により既存クラウド接続は不要と決定された。

## 決定

- firmware から既存クラウド接続（XiaoZhi 連携・アカウント連携・アプリストア連携など、クラウド前提の通信処理）を削除する
- firmware の接続先は PC バックエンド（`backend/`）のみとする
- `server/`（Go クラウドサーバー）と `app/`（モバイルアプリ）のクラウド依存機能は未使用となるが、ディレクトリの削除は行わない（改修対象外・保守対象外として残置）

## 検討した選択肢

- A: 既存クラウド接続と新 backend を切り替え可能にして併存 — 設定・認証・状態管理が二重化し保守コストが高い。使わない機能のために抽象を増やすことになる
- B: 既存クラウド接続を削除（採用）— 接続先が一本化され、設定責務・状態管理・エラーハンドリングが単純になる

## 理由

オーナーが既存クラウド機能を使わないと明言したため、併存させる理由がない。削除により firmware のメモリ・コードサイズにも余裕が生まれる。

## 影響

- 削除対象の正確な範囲（該当 HAL モジュール、OTA・ESP-NOW・BLE など残す機能との依存関係）は Phase 0 の調査で特定してから削除する。**調査前に雰囲気で消さない**
- クラウド接続を前提とした既存機能（アプリ連携での視聴・リモートアバター等）は失われる。必要になれば backend 側で同等機能を再実装する
- OTA アップデートの配信元をどうするかは別途決定が必要（backend からの配信 or 手動書き込み）。決定時に ADR を起こす
